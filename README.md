# MiouModPack

A Valheim modpack that keeps our dedicated server's mods in sync, so updates don't mean uploading every mod and config by hand. The mods included **may change** depending on our preferences.

## Installation

**Server (Pterodactyl):** Stop the server, set the modpack in the Valheim egg's startup settings to the latest version of the dependency (e.g. `Miou-MiouModPack-1.0.3`), and reinstall the server. If the installation fails with a 502 error, add a slash at the end (e.g. `Miou-MiouModPack-1.0.3/`).

**Client:** Install the pack with r2modman or the Thunderstore app, then launch Valheim through the manager. Clients must run the same pack version as the server.
